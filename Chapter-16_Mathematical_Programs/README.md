## Compilation

Compile a program using GCC:

```bash
gcc 01_addition.c -o addition
```

Run:

```bash
./addition
```

Programs using the math library (`math.h`) require linking with `-lm`:

```bash
gcc 20_compound_interest.c -o compound_interest -lm
gcc 23_quadratic_equation.c -o quadratic_equation -lm
```
