# Chapter 17 - Pattern Programs

This chapter contains a collection of pattern printing programs written in the C programming language. Pattern programs are an excellent way to understand nested loops, conditional statements, and logical thinking. They are also frequently asked in programming interviews and laboratory examinations.

---

## Learning Objectives

After completing this chapter, you will be able to:

- Understand nested `for` loops
- Print different types of patterns
- Work with spaces and formatting
- Improve logical thinking and problem-solving skills
- Build confidence in loop-based programming

## Compilation

Compile a program using GCC:

```bash
gcc 01_right_triangle_star.c -o right_triangle
```

Run the executable:

### Windows

```bash
right_triangle.exe
```

### Linux/macOS

```bash
./right_triangle
```

## Expected Learning Outcome

After completing this chapter, students should be able to:

## Recommended Practice

After understanding each program:

- Change the number of rows.
- Modify stars (`*`) into numbers or alphabets.
- Try printing the same pattern upside down.
- Convert solid patterns into hollow patterns.
- Create your own custom pattern.
